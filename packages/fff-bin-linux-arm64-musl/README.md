# @sakiori/fff-bin-linux-arm64-musl

The native part of [`@sakiori/fff-node`](https://www.npmjs.com/package/@sakiori/fff-node) for Linux ARM64 (musl): the fff C library and the `fff-mcp` shared service executable, both from one build.

Do not install this package directly. Install `@sakiori/fff-node`, which lists it as an optional dependency at its own exact version, so npm and pnpm install it only on the platform it matches.
